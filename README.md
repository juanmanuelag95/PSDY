# Servicios Yucatán — Administración y reportes
Módulo del Equipo 3 (Edwin, Juan, Caro, Joel). Panel estático para gestionar usuarios, ver reportes, exportar datos y hacer operaciones administrativas.
Sitio pensado para GitHub Pages. La base de datos simulada está en `data/db.json`.
## Cómo abrirlo
En GitHub: Settings → Pages → rama `main` → carpeta `/`.
En local, abre `index.html` en el navegador.
